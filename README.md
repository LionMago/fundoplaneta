# Planeta Reggae — Halloween

Fundo animado para xatframe, com fumaça lenta para a direita e morcegos articulados.

## Publicar no GitHub Pages

Enviar os arquivos ao repositório não ativa a hospedagem.

1. Abra [Settings → Pages](https://github.com/LionMago/fundoplaneta/settings/pages).
2. Em **Source**, selecione **Deploy from a branch**.
3. Escolha a branch **main**, a pasta **/(root)** e clique em **Save**.
4. Aguarde o término da publicação em **Actions**.
5. Abra https://lionmago.github.io/fundoplaneta/ e use esse endereço no campo xatframe do grupo.

O arquivo `index.html` deve ficar na raiz. Preserve a pasta `fonts/`.
Não há instalação de dependências ou etapa de build.
O arquivo `.nojekyll` mantém a publicação dos arquivos estáticos sem processamento pelo Jekyll.

Se aparecer **404 — There isn't a GitHub Pages site here**, confira a configuração acima.
As porcentagens de CSS, JavaScript e HTML na página do repositório são apenas estatísticas de linguagens.

## Prévia

Abra `index.html` ou `previa.html`. As duas páginas mostram somente o fundo.
